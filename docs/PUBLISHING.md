# Publishing CloudFlow on GitHub

**Repository:** `savantadarsh/cloudflow-saas-commercial-analytics`

## Before publishing

Confirm you have the rights to redistribute the provided CSV dataset. Names and email addresses are pseudonymised, but that does not establish redistribution rights. Review [`licensing_note.md`](licensing_note.md) and [`data_publication.md`](data_publication.md).

## Upload using GitHub's website

1. Open the repository at `https://github.com/savantadarsh/cloudflow-saas-commercial-analytics`.
2. Extract the release ZIP on your computer. Open the extracted `cloudflow-saas-commercial-analytics` folder.
3. If the repository is empty, choose **uploading an existing file**. Otherwise choose **Add file → Upload files**.
4. Drag the **contents** of the extracted folder (including `.github`, `sql`, `data`, `outputs`, `docs`, and `README.md`) into GitHub. Do not upload the ZIP itself.
5. Review the file paths, enter a commit message, and click **Commit changes**.
6. Check that GitHub renders the README, all seven figures, and the executive PDF. Review the **Actions** tab for the repository structure check.

**Important:** Uploading files through the GitHub website does not delete files that are already on GitHub. If updating an existing repository, review its file tree and delete any unwanted files separately. You can alternatively use Git locally to synchronise the repository contents.
